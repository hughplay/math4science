# Math4Science — AI4Science 数学研究训练系统

面向深度学习与 AI4Science 研究者的中文数学学习网站。

## 访问网站

GitHub Pages: https://hughplay.github.io/math4science/

如果尚未发布：进入 [Settings → Pages](https://github.com/hughplay/math4science/settings/pages)，选择 **Deploy from a branch**，分支 **main**，目录 **/(root)** 并保存。

## 内容

- 12 周训练路线、36 个学习单元
- Week 1 的详细中文讲义、逐步推导、知识补缺和参考章节
- 数学推导工作台、交互可视化、研究假设记录与学习进度
- [labs/](labs/) 中四个 Python 实验（条件 FM、ODE 误差、SO(3) 插值、OT coupling）

## 本地使用

直接打开仓库根目录的 `index.html`，或下载仓库 ZIP 解压后打开。Python 实验请在本地安装脚本顶部注明的依赖并单独运行。

## 隐私

学习进度和笔记使用浏览器 localStorage，仅保存在当前浏览器，不自动同步到 GitHub。更换设备前请用站内备份功能导出。

## 更新

修改 `index.html` 后提交到 `main` 分支，GitHub Pages（启用后）会重新发布。
