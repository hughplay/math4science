这些 PDF 是从有明确再分发许可的公开教材/课程讲义中**按原始页截取**的学习材料，不是本项目原创教材。

其中 MIT 讲义和 Calculus Vol. 3 节选仅供非商业性学习与传播；保留原页中的署名和来源标记，并依照 CC BY-NC-SA 许可分享。OpenStax 内容每页原本的 “Access for free at openstax.org” 署名不得删除。请根据各文件自身许可进行使用，不能将全部文件笼统标成同一个开源软件许可。

文件和原始 PDF 页码可见 [manifest.json](manifest.json)，记录了每份节选的真实源地址以及裁剪范围。如果某个资源未能下载或定位，见其中的 `warnings`，**不要把缺失的 PDF 当成已经部署**。

由于 [*Mathematics for Machine Learning*](https://mml-book.github.io/book/mml-book.pdf) 的官方免费 PDF 只许可个人浏览与下载，不允许再分发，因此不包含在这里。其他版权或 arXiv 投稿许可尚未核实的资料也只保留原始官方链接。

构建脚本：[scripts/build_readings.py](../scripts/build_readings.py)。重跑方法：GitHub Actions → **Build licensed chapter PDFs** → Run workflow。
